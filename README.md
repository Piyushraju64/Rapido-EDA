# 🚗 Rapido Ride Data Analysis using Python

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Rapido ride-booking data using Python.

The main objective is to analyze ride patterns, service preferences, cancellations, fare distribution, revenue, customer travel patterns, payment methods, ride distance, and ride duration.

The analysis helps identify useful business patterns that can support better driver allocation, operational planning, customer experience, and revenue optimization.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze completed and cancelled rides
* Understand the popularity of different Rapido services
* Identify cancellation patterns
* Analyze ride demand over time
* Compare ride demand across days of the week
* Analyze revenue generated by different services
* Compare average fares across services
* Identify popular pickup and destination locations
* Identify the most frequently travelled routes
* Analyze payment-method usage
* Understand ride distance and duration
* Study the relationship between distance, duration, and total fare

---

## 📊 Dataset

The dataset contains Rapido ride-booking information with details such as:

| Column           | Description                               |
| ---------------- | ----------------------------------------- |
| `booking_id`     | Unique identifier for each booking        |
| `date`           | Date of the ride                          |
| `time`           | Time information associated with the ride |
| `services`       | Type of Rapido service                    |
| `ride_status`    | Status of the ride                        |
| `source`         | Pickup location                           |
| `destination`    | Destination location                      |
| `duration`       | Ride duration                             |
| `distance`       | Ride distance                             |
| `ride_charge`    | Ride charge                               |
| `misc_charge`    | Miscellaneous charge                      |
| `total_fare`     | Total fare of the ride                    |
| `payment_method` | Payment method used                       |

## 🧹 Data Cleaning

The dataset was checked for:

* Missing values
* Duplicate records
* Data types
* Date formatting

The `date` column was converted into a datetime format for time-based analysis.

Missing values were found in:

* `ride_charge`
* `misc_charge`
* `total_fare`
* `payment_method`

These missing values were associated with cancelled rides.

For cancelled rides, the fare-related fields were handled appropriately, and the payment method was marked as **Not Applicable**.

## 🔍 Exploratory Data Analysis

### 1. Ride Status Analysis

The project analyzes the distribution of completed and cancelled rides.

This helps understand the overall success rate of bookings and highlights potential opportunities for reducing cancellations.

### 2. Service Analysis

The number of rides for each Rapido service was analyzed to understand customer preferences and service demand.

### 3. Total Fare Analysis

The distribution of total fares was analyzed to understand typical ride pricing and identify high-value rides.

### 4. Time Analysis

Ride demand was analyzed based on time information to identify periods with higher ride activity.

### 5. Daily Ride Trends

Daily ride volumes were analyzed to understand fluctuations in demand over time.

### 6. Day-of-Week Analysis

Ride demand was compared across different days of the week to identify weekly demand patterns.

### 7. Revenue by Service

Total revenue generated by each service was compared to understand the contribution of different services to overall revenue.

### 8. Daily Revenue Trend

Daily revenue was analyzed to identify revenue fluctuations and potential high- and low-performing periods.

### 9. Average Fare by Service

Average fare was compared across different services to understand revenue generated per ride.

### 10. Pickup Location Analysis

The top pickup locations were identified to understand areas with high customer demand.

### 11. Destination Analysis

The most common destinations were analyzed to understand customer travel patterns.

### 12. Top Routes Analysis

The most frequently travelled source-to-destination routes were identified.

This can help with driver allocation and operational planning.

### 13. Payment Method Analysis

Different payment methods were analyzed to understand customer payment preferences.

### 14. Distance Analysis

Ride-distance distribution was analyzed to understand the typical distance travelled by customers.

### 15. Duration Analysis

Ride duration was analyzed to understand the typical length of Rapido trips.

### 16. Correlation Analysis

The relationships between:

* Distance
* Duration
* Total Fare

were analyzed using a correlation matrix.

## 💡 Key Business Insights

The analysis provides several business-oriented insights:

* Understanding completed versus cancelled rides can help identify opportunities to reduce cancellations.

* Daily and weekly ride trends can help with driver allocation and operational planning.
* Revenue-by-service analysis helps identify which services contribute significantly to total revenue.

* High-demand pickup locations can be prioritized for driver availability.
